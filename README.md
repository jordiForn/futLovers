# FutLovers

Plataforma para encontrar, organizar y jugar partidos de fútbol.
## Objetivo

Crear la mayor comunidad de fútbol amateur de España.

## MVP

- Registro de usuarios
- Geolocalización
- Visualización de partidos
- Crear partidos
- Unirse a partidos
- Lista de espera
- Nivel de jugador
- Sistema de fiabilidad

## Stack

### Frontend
- Angular
- TypeScript

### Backend
- Supabase
- PostgreSQL

### Deployment
- Vercel
