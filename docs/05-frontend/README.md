# Frontend

Frontend de FutLovers desarrollado con Angular.

## Objetivo

Proporcionar la interfaz web de FutLovers para descubrir, crear y
participar en partidos de fútbol.

## Tecnología

- Angular
- TypeScript
- SCSS
- Supabase JS

## Funcionalidades MVP

- Registro e inicio de sesión
- Geolocalización
- Selección de ubicación
- Visualización de partidos
- Detalle de partido
- Crear partido
- Unirse a un partido
- Abandonar un partido
- Perfil de usuario
- Reserva de campos
