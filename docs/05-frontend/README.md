# Frontend

Aplicación Angular de FutLovers.

## Tecnología

- Angular 21
- TypeScript (strict)
- Tailwind CSS
- Supabase JS

## Funcionalidades MVP

- Registro e inicio de sesión
- Geolocalización y selección de ubicación (fallback Dénia)
- Visualización de partidos de hoy
- Detalle de partido
- Crear partido
- Unirse y abandonar un partido
- Perfil de usuario

La reserva de campos no forma parte de este MVP.
