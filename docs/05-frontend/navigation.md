# Navigation

## Navegación principal

- Jugar
- Crear
- Perfil

Reservar queda fuera del MVP.

## Rutas

| Ruta | Pantalla | Autenticación |
| --- | --- | --- |
| `/` | Partidos de hoy | No |
| `/login` | Login | No |
| `/register` | Registro | No |
| `/matches/:id` | Detalle partido | No |
| `/create` | Crear partido | Sí |
| `/profile` | Perfil | Sí |

Unirse y abandonar un partido requieren sesión, aunque el detalle sea público.
