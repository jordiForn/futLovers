# Reglas de partidos

## Capacidad

Un partido F5 tiene 10 jugadores.

## Unirse

Un usuario no puede unirse dos veces
al mismo partido.

## Cancelación

Cancelación > 24h:
sin penalización.

Cancelación < 2h:
penalización leve.

No-show:
penalización alta.

## Lista de espera

Cuando una plaza queda libre:
se notifica al primer usuario compatible.
